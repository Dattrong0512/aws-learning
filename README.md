# AWS Learning

A bilingual study guide for the AWS Certified Solutions Architect – Associate
(SAA-C03) exam, with 22 sections and 124 topics. The website includes concise
study notes, service comparisons, topic navigation, and content search.

Each topic covers an overview, purpose, how it works, a practical example, and
comparisons. Each major service page ends with **Exam Tips — SAA-C03**.

## Languages

- [English](https://aws.trongle.tech/en/)
- [Vietnamese](https://aws.trongle.tech/)

Switch between English and Vietnamese while keeping the current study section.

## AWS services and topics

- Identity and access: IAM, advanced IAM, and AWS Organizations.
- Compute: EC2, Auto Scaling, Elastic Load Balancing, and Elastic Beanstalk.
- Storage: S3, EBS, EFS, and additional AWS storage services.
- Databases: RDS, Aurora, ElastiCache, and purpose-built databases.
- DNS and content delivery: Route 53, CloudFront, and Global Accelerator.
- Messaging and streaming: SQS, SNS, Kinesis, and Amazon MQ.
- Containers: ECS, Fargate, ECR, and EKS.
- Serverless: Lambda and serverless architecture.
- Data analytics and machine learning.
- Monitoring and auditing: CloudWatch and related services.
- Security and encryption: AWS KMS and related security concepts.
- Networking: VPC and hybrid connectivity.
- Disaster recovery and migrations.
- Architecture: AWS Well-Architected and Trusted Advisor.
- Governance, cost management, and other AWS services.
