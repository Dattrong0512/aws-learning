Amazon Rekognition & Textract

Mục đích: Đây là các dịch vụ ML có sẵn để xử lý image, video và document.

Rekognition = hiểu nội dung image / video

Textract = đọc document / scan = lấy text + table + form

1. Amazon Rekognition

Rekognition dùng để phân tích hình ảnh/video:

Image / Video
↓
Rekognition
↓
Object / Person / Face / Text / Scene

Có thể dùng cho: Object Detection · Face Detection · Face Search / Compare · Text Detection · Content Moderation

Ví dụ:

User upload image
↓
Rekognition
↓
phát hiện:
Car
Person
Dog
Text

2. Content Moderation

Dùng để phát hiện nội dung nhạy cảm/không phù hợp.

Image / Video
↓
Rekognition Moderation
↓
Confidence Score

Có thể đặt threshold:

Confidence cao
→ Flag

Không chắc chắn
→ Human Review

Human review có thể dùng: Amazon A2I = đưa kết quả ML cho người kiểm tra lại

3. Amazon Textract

Textract dùng để lấy dữ liệu từ document.

PDF / Scan / Image
↓
Textract
↓
Text
Handwriting
Form
Table
Invoice / Form
↓
Textract
↓
Name
DOB
Invoice Number
Amount

Textract mạnh hơn OCR cơ bản vì có thể hiểu form và table, không chỉ đọc chữ.

↓

PDF / Scan

Amazon Transcribe, Polly & Translate

Mục đích: Đây là các dịch vụ ML có sẵn để xử lý giọng nói và ngôn ngữ, không cần tự train model.

Transcribe
= Speech → Text

Polly
= Text → Speech

Translate
= Text ngôn ngữ A → Text ngôn ngữ B

1. Amazon Transcribe

Transcribe dùng Automatic Speech Recognition (ASR) để chuyển audio thành text.

Audio / Voice
↓
Transcribe
↓
Text Transcript

Ví dụ:

Customer Call
↓
Transcribe
↓
Call Transcript

Có thể dùng cho: Call transcript · Subtitle / Caption · Searchable video/audio

Ngoài ra hỗ trợ: Language Identification = tự nhận diện ngôn ngữ

PII Redaction = che/xóa thông tin cá nhân khỏi transcript

2. Amazon Polly

Polly chuyển text thành giọng nói.

Text
↓
Polly
↓
Speech Audio
"Welcome to our application"
↓
Polly
↓
🔊 Voice

Có thể tùy chỉnh cách đọc bằng: Lexicon = chỉnh cách đọc từ / tên / acronym

SSML = chỉnh pronunciation / emphasis / speaking style

Polly = Text-to-Speech.

3. Amazon Translate

Translate dùng để dịch text giữa các ngôn ngữ.

English Text
↓
Translate
↓
Vietnamese Text

Phù hợp cho: Website localization · Product description · Notification · Application đa ngôn ngữ

4. Flow kết hợp

Ba service có thể ghép với nhau:

Customer Call
↓
Transcribe
↓
Text
↓
Translate
↓
Ngôn ngữ khác
↓
Polly
↓
Speech
English Voice
↓
Transcribe
↓
English Text
↓
Translate
↓
Vietnamese Text
↓
Polly
↓
Vietnamese Voice

5. Use Cases

Use cases:

Video / Call
↓
Transcribe
↓
Subtitle / Transcript
Application Text
↓
Polly
↓
Voice / Accessibility
Website Content
↓
Translate
↓
Multi-language Website

Transcribe = speech-to-text; Polly = text-to-speech; Translate = dịch ngôn ngữ.

Amazon Lex & Amazon Connect

Mục đích: Amazon Lex dùng để tạo chatbot/voice bot hiểu ý người dùng, còn Amazon Connect là cloud contact center để nhận cuộc gọi và điều phối contact flow.

Lex = hiểu speech/text = nhận diện intent

Connect = nhận call = điều phối contact flow

1. Amazon Lex

Lex dùng:

ASR
= Speech → Text

NLU
= hiểu user muốn làm gì

Ví dụ:

"Tôi muốn đặt lịch ngày mai"
↓
Lex
↓
Intent = BookAppointment

Intent = mục đích của người dùng, không chỉ là keyword.

Lex phù hợp cho: Chatbot · Voice Bot · Call Center Bot

2. Amazon Connect

Amazon Connect là cloud contact center.

Caller
↓
Amazon Connect
↓
Contact Flow
↓
Bot / Agent / Backend

Connect có thể: Nhận cuộc gọi · Route cuộc gọi · Tạo contact flow · Chuyển sang agent · Tích hợp CRM / AWS services

3. Connect + Lex + Lambda

Flow phổ biến:

Caller
↓
Amazon Connect
↓
Amazon Lex
↓
nhận diện Intent
↓
Lambda
↓
CRM / Backend

Ví dụ đặt lịch:

"Tôi muốn đặt lịch 3 giờ chiều"
↓
Connect
↓
Lex
→ Intent = BookAppointment
↓
Lambda
↓
CRM
↓
Tạo appointment

4. Khi Bot không xử lý được

Lex confidence thấp
hoặc
case chưa được thiết kế
↓
Fallback
↓
Human Agent

Backend vẫn cần: Validate input · Authorization · Business Rules · Idempotency

vì Lex chỉ hiểu intent, không tự quyết định được phép thay đổi dữ liệu hay không.

5. Use Cases

Use cases:

Customer Call
↓
Connect + Lex
↓
FAQ / Booking / Order Status
Request đơn giản
↓
Bot xử lý

Request phức tạp
↓
Human Agent
Nhớ nhanh · SAA-C03

Lex xây chatbot với intent/slot; Connect cung cấp contact center managed, có thể tích hợp Lex.

Amazon SageMaker AI

Mục đích: Amazon SageMaker AI là dịch vụ managed để xây, train, tune và deploy custom Machine Learning model.

SageMaker = Build ML Model = Train = Tune = Deploy = Predict

Khác với các AI service có sẵn như Translate hay Textract:

Translate / Textract = model AWS làm sẵn

SageMaker = bạn tự train model cho bài toán riêng

1. ML Flow cơ bản

Historical Data
↓
Features + Labels
↓
SageMaker Training
↓
Model
↓
New Data
↓
Prediction

Ví dụ:

Historical Students
↓
Study Time + Experience
↓
Exam Result
↓
Train Model
↓
New Student
↓
Predict Pass / Fail

2. Training Data

Training thường cần: Features = thông tin đầu vào

Label = kết quả cần model học

Study Hours
AWS Experience
IT Experience
↓
Features

Exam Score
↓
Label

Model học quan hệ giữa feature và label để dự đoán data mới.

3. Train / Tune / Deploy

  • Train = model học từ historical data
  • Tune = thử các cấu hình để model tốt hơn
  • Deploy = đưa model ra endpoint để application gọi
Train
↓
Tune
↓
Model Artifact
↓
Deploy Endpoint
↓
Application
↓
Prediction

4. Managed nhưng vẫn phải kiểm tra model

SageMaker quản infrastructure, nhưng model vẫn phụ thuộc vào:

Training Data · Feature · Label · Model Quality

Nếu data sai:

Bad Data
↓
Bad Model
↓
Bad Prediction

Ngoài ra cần monitor: Model Quality · Data Drift · Prediction Quality

5. Use Cases

Use cases:

Customer History
↓
SageMaker
↓
Churn Prediction
Transaction Data
↓
SageMaker
↓
Fraud Risk Score
Sales History
↓
SageMaker
↓
Demand Forecast

6. SageMaker Batch Transform vs Real-Time Endpoint

Chế độ InferenceCơ chế & Trường hợp sử dụng
SageMaker Batch TransformChạy suy luận dự đoán hàng loạt (offline batch inference) trên tập dữ liệu lớn lưu trong S3 rồi ghi kết quả ra S3, tự tắt compute khi xong job — dùng khi không cần kết quả tức thời theo từng request (không dùng cho ETL làm sạch dữ liệu)
SageMaker Real-Time EndpointDuy trì HTTPS endpoint hoạt động liên tục để trả dự đoán độ trễ thấp (milliseconds) cho từng request trực tuyến
Nhớ nhanh · SAA-C03

SageMaker AI là nền tảng quản vòng đời machine learning từ chuẩn bị dữ liệu/huấn luyện đến deployment.

Amazon Kendra & Amazon Personalize

Mục đích: Amazon Kendra dùng để search và tìm câu trả lời trong document, còn Amazon Personalize dùng để gợi ý nội dung/sản phẩm phù hợp cho từng user.

Kendra = Intelligent Document Search

Personalize = Recommendation Engine

1. Amazon Kendra

Kendra dùng ML để search trong knowledge base bằng ngôn ngữ tự nhiên.

Documents
↓
Kendra Index
↓
User Question
↓
Relevant Answer / Result

Nguồn dữ liệu có thể là: S3 · RDS · Google Drive · SharePoint · OneDrive · Salesforce · ServiceNow · PDF / Word / HTML / FAQ

Ví dụ:

"IT support desk ở đâu?"
↓
Kendra
↓
tìm câu trả lời trong tài liệu nội bộ

Kendra = search thông minh trên document, không chỉ match keyword đơn giản.

2. Amazon Personalize

Personalize dùng hành vi user để tạo recommendation.

User / Item / Interaction Data
↓
Personalize
↓
Recommendation
User mua Gardening Tools
↓
Personalize
↓
gợi ý:
Seeds
Gloves
Watering Can

Có thể dùng cho: Website · Mobile App · Email · SMS

Ngoài recommend item, Personalize còn có thể:

Re-rank list = sắp xếp lại danh sách theo từng user

3. Kendra vs Personalize

Kendra = "User đang tìm thông tin gì?"

Personalize = "User này nên thấy item gì tiếp theo?"

Documents
↓
Kendra
↓
Search / Answer
User Behavior
↓
Personalize
↓
Recommendation

4. Use Cases

Use cases:

Company Documents
↓
Kendra
↓
Employee Search
FAQ / PDF / Knowledge Base
↓
Kendra
↓
Customer Support Search
User Purchase / Click History
↓
Personalize
↓
Product Recommendation
Nhớ nhanh · SAA-C03

Kendra là enterprise search; Personalize tạo gợi ý cá nhân hóa dựa trên dữ liệu hành vi.
